# もやもやメモ ― 「思い出せない」記録＆AI分析Webアプリ

文字・音声・手書き・写真のどれからでも「あれ、なんだっけ？」を記録し、Geminiが候補を推論、確定した正解を自動分類して傾向をグラフ化します。

```
moyamoya-memo/
├── index.html      … フロントエンド（GitHub Pagesで公開）
└── gas/Code.gs     … バックエンド（GASに貼り付け）
```

---

## 1. スプレッドシート定義

シートと見出しは `setup()` 実行時に自動作成されます。既存の Records シートに列が足りない場合は、右端に自動追加されます（列の並び順は自由、見出し名で読み書きします）。

### Users シート

| 見出し | 型 | 用途 |
|---|---|---|
| ユーザーID | 文字列 | `U` + 12桁の一意ID |
| メールアドレス | 文字列 | ログインID（小文字で保存） |
| 表示名 | 文字列 | 画面表示・Driveフォルダ名 |
| パスワードハッシュ | 文字列 | SHA-256 を200回ストレッチ（平文は保存しない） |
| ソルト | 文字列 | ユーザーごとのランダム値 |
| 要パスワード変更 | 真偽値 | 仮パスワード発行後 TRUE、変更で FALSE |
| ログイン失敗回数 | 数値 | 5回でロック |
| ロック解除日時 | 日時 | ロック中はこの日時まで拒否（15分） |
| 登録日時 | 日時 | |
| 最終ログイン日時 | 日時 | |

### Records シート

| 見出し | 型 | 用途 |
|---|---|---|
| 記録ID | 文字列 | `R` + 日時 + 乱数 |
| ユーザーID | 文字列 | Users との紐づけ |
| 記録日時 | 日時 | サーバーで記録した時刻（解決時間の起点） |
| 発生日時 | 日時 | 思い出せなかった時刻（ユーザー入力） |
| 状況 | 文字列 | 会話中／テレビ・動画／本・雑誌／仕事中／外出・旅先／家事中／その他 |
| 手がかり | 文字列 | 入力テキスト（音声書き起こし含む）。再推論時は「＋ 追加分」を追記 |
| **入力手段** | 文字列 | `テキスト,音声,手書き,写真` のカンマ区切り（複数可） |
| **画像URL** | 文字列 | DriveのファイルURL（複数は改行区切り） |
| 画像ファイルID | 文字列 | DriveファイルID（カンマ区切り、表示・削除用） |
| 画像種別 | 文字列 | `photo` / `handwriting`（画像ファイルIDと同じ順） |
| 抽出キーワード | 文字列 | Geminiが口語から拾ったキーワード（「、」区切り） |
| AI解釈 | 文字列 | 探している対象の言い換え |
| AI候補(JSON) | JSON文字列 | `[{name, confidence, reason, category}]` 最大3件 |
| 正解 | 文字列 | 確定した答え |
| カテゴリ | 文字列 | 人名／エンタメ／日用品・モノ／場所・地名／言葉・用語／予定・タスク／その他 |
| サブカテゴリ | 文字列 | 俳優・映画・植物など |
| タグ | 文字列 | カンマ区切り |
| 覚え方ヒント | 文字列 | Geminiによる次回用の連想ヒント |
| 解決方法 | 文字列 | `AI候補` / `自力` |
| 解決日時 | 日時 | |
| 解決までの分数 | 数値 | 解決日時 − 記録日時 |
| ステータス | 文字列 | `未解決` / `解決` |

### Sessions シート

| 見出し | 型 | 用途 |
|---|---|---|
| トークン | 文字列 | ログイン時に発行（端末の localStorage に保存） |
| ユーザーID | 文字列 | |
| 有効期限 | 日時 | 発行から30日 |

## 2. Google Drive の保存構成

```
もやもやメモ/                   ← ROOT_FOLDER_ID（未設定なら自動作成）
└── users/
    └── 表示名_ユーザーID/
        ├── images/   … 写真・手書き（例: 20260925_101500_R2609..._写真1.jpg）
        └── exports/  … Markdown / CSV の書き出し
```

GASは「自分（デプロイしたアカウント）として実行」するため、画像はすべて運営者のDriveに会員別フォルダで保存されます。ファイルは非公開のままで、アプリ内のサムネイルはGAS経由（本人の記録に属する画像のみ）で表示します。

## 3. セットアップ手順

### 3-1. スプレッドシートとGAS
1. Googleドライブで新しいスプレッドシートを作成（名前例：`もやもやメモDB`）。
2. メニュー「拡張機能 → Apps Script」を開き、`コード.gs` の中身をすべて `gas/Code.gs` の内容に置き換えて保存。
3. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に追加：

   | プロパティ | 値 | 必須 |
   |---|---|---|
   | `GEMINI_API_KEY` | Google AI Studio で発行したキー | 必須 |
   | `GEMINI_MODEL` | `gemini-2.5-flash`（既定） | 任意 |
   | `ROOT_FOLDER_ID` | 保存先フォルダのID（URLの `folders/` 以降） | 任意 |
   | `SPREADSHEET_ID` | スタンドアロンGASで使う場合のみ | 任意 |

4. エディタ上部の関数選択で `setup` を選び「実行」→ 権限を承認（スプレッドシート・Drive・メール送信・外部通信）。実行ログにスプレッドシートとフォルダのURLが出れば完了。

### 3-2. ウェブアプリとしてデプロイ
1. 「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」。
2. 次のユーザーとして実行：**自分**、アクセスできるユーザー：**全員**。
3. 発行された `https://script.google.com/macros/s/…/exec` をコピー。
4. コード修正後は「デプロイを管理 → 編集 → バージョン：新バージョン」で更新（URLは変わりません）。

### 3-3. フロントエンド
1. `index.html` の冒頭付近にある `const GAS_URL = '…'` を 3-2 のURLに書き換え。
2. GitHubで新規リポジトリ（例：`moyamoya-memo`）を作成し、`index.html` をコミット＆プッシュ。
3. リポジトリの「Settings → Pages」で Branch を `main` / `/(root)` にして Save。
4. 数分後 `https://kenken6291.github.io/moyamoya-memo/` で公開されます。

> 音声入力・カメラは HTTPS 必須です。GitHub Pages なら問題ありません。ローカルの `file://` では音声入力が動かないブラウザがあります。

## 4. 動作メモ

- **音声入力**：Chrome（Android/PC）・Safari（iOS 14.5以降）で動作。無音で自動停止する端末でも、マイクをONにしている間は自動で再開します。つなぎ言葉や誤変換はGemini側のプロンプトで吸収しています。
- **手書き**：Pointer Events（非対応端末は Touch/Mouse Events）で描画。白背景PNG・長辺1000px以内で送信。
- **写真**：ブラウザで長辺1000px・JPEG品質0.8に縮小してから送信。1回4枚まで。
- **人物写真**：Geminiには「顔だけで実在の人物を特定しない」よう指示しています。テロップ・雑誌の見出し・名札など画像内の文字や、テキストの手がかりがあれば候補を出します。
- **再推論**：結果画面の「手がかりを足してもう一度」で、同じ記録に手がかりを追記して聞き直せます（添付画像も再利用）。
